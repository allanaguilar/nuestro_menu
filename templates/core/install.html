Instalar Nuestro Menú

Puedes usarla desde el navegador o instalarla como aplicación. Hace falta conexión; no se edita sin red.

Android

  1. Abre la web en Chrome.
  2. Toca el menú y elige Añadir a pantalla de inicio o Instalar aplicación.

iPhone

  1. Abre la web en Safari.
  2. Pulsa el botón de compartir y elige Añadir a pantalla de inicio.

Ordenador

En Chrome o Edge, usa el icono de instalación en la barra de direcciones si aparece.
